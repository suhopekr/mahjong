# 사운드 파일 넣는 법

이 폴더는 **비어 있어도 게임이 정상 동작한다.** 파일이 없으면
`src/core/audio.js`의 합성음으로 자동 폴백한다. 아래는 실제 녹음 음원을
쓰고 싶을 때의 절차다.

## 1. 파일명 규칙

파일 이름의 **첫 토큰이 역할(role)** 이다. `<role>[-<변형>].<확장자>`

| role | 언제 나는 소리 | 변형 권장 |
|---|---|---|
| `impact` | **돌끼리 부딪힘** — 이 게임의 중심 사운드 | **4~6개** |
| `obstacle` | 나무 말뚝/벽에 부딪힘 (둔하고 짧게) | 2~3개 |
| `bumper` | 놋쇠 범퍼 (밝고 길게 울리는 금속) | 2개 |
| `portal` | 포털 통과 (부드럽게, 타격감 없이) | 1개 |
| `flick` | 발사(손가락으로 튕기는 순간) | 2개 |
| `fall` | 돌이 판 밖으로 떨어짐 | 1~2개 |
| `sink` | 돌이 구멍에 빠짐 | 1개 |
| `win` | 스테이지 클리어 | 1개 |
| `lose` | 전멸 | 1개 |
| `button` | UI 버튼 | 1개 |

예: `impact-01.mp3`, `impact-02.mp3`, `obstacle-1.mp3`, `sink.mp3`

**앞부분 잘라내기 — 실측이 필요하다.** `samples.js`의 `findOnset()`은
피크의 1%를 넘는 첫 샘플을 시작점으로 잡는데, 그게 항상 진짜 타격점은
아니다. `wood-hit.wav`는 타격이 **146ms 지점**에 있고 그 앞 146ms가
-38dB 방 소음이었다 — 1% 기준으로는 16ms에서 걸려서, 그대로 썼으면
말뚝에 부딪힐 때마다 **130ms 늦게** 소리가 났을 것이다. 넣기 전에 항상
포락선을 찍어보고, 피크에서 뒤로 걸어가 진짜 어택 시작을 찾아 자른다.

**변형이 왜 필요한가:** 핀볼 스테이지는 1초에 충돌이 열 번도 난다.
같은 파일이 연달아 나오면 기관총 소리가 된다. 코드가 "직전에 쓴 변형은
안 고르기"로 순환시키니 4개만 있어도 충분히 자연스러워진다.

## 2. 넣고 나서

```
npm run audio:manifest
```

`assets/audio/manifest.json`이 실제 폴더 내용대로 다시 써지고, 어떤
role이 채워졌고 어떤 게 아직 합성음인지 표로 찍어준다. **이걸 안 돌리면
파일이 있어도 안 읽힌다** (일부러 그렇게 했다 — 없는 파일을 하나씩
찔러보면 콘솔이 404로 도배되고, 그러면 나중에 진짜 에러를 놓친다).

## 2-0. 같은 이름으로 내용만 바꾸지 말 것

음원 파일은 `cache: "force-cache"`로 받는다 — 한 번 받으면 다시 안
물어본다. 그래서 `impact-01.mp3`의 **내용만** 바꿔서 덮어쓰면, 이미 한
번이라도 게임을 켰던 사람에게는 영원히 옛날 소리가 난다. 소리를 바꿀
때는 **번호를 올리거나 이름을 바꾼다** (`impact-01.mp3` → `impact-02.mp3`).

`manifest.json`은 반대다. "지금 뭐가 있는지"를 알려주는 목록이라서 항상
재검증한다(`no-cache`, 보통 304). 원래는 이것도 `force-cache`였고, 그게
실제 버그였다 — 새 음원을 넣었는데 브라우저가 목록을 다시 안 물어봐서
게임이 파일의 존재 자체를 몰랐다.

## 2-1. `_source/` 폴더

원본 파일(자르기 전 wav 등)은 `_source/`에 넣는다. manifest 스크립트는
확장자로 거르기 때문에 폴더는 무시하고, 나중에 다시 인코딩할 때 원본이
필요하다. **ZIP 빌드는 `assets/audio/_source/`를 반드시 제외해야 한다** —
원본 wav 하나가 mp3 20개보다 크다.

## 3. 포맷 / 용량 기준

- **mp3, 모노, 96kbps.** 실측으로 확인한 것: Chromium은 mp3의 인코더
  지연을 제대로 제거해서 디코딩 후 시작점이 **0.02ms**다. 같은 소리가
  wav 12.8KB vs mp3 2.6KB — 5분의 1이다.
- **앞 무음은 코드가 알아서 잘라낸다.** `src/core/samples.js`의
  `findOnset()`이 디코딩된 샘플을 훑어서 실제로 들리기 시작하는 지점부터
  재생한다. 그래서 (a) 파일 앞에 붙은 룸톤/무음과 (b) iOS Safari가 남길 수
  있는 코덱 지연이 **둘 다** 자동으로 사라진다. 그래도 원본을 다듬어 오면
  더 좋다 — 코드가 봐주는 건 앞부분뿐이고 **뒤쪽 꼬리는 직접 잘라야 한다.**
- 길이: `impact`/`obstacle`/`bumper`/`flick`은 **150ms 이하**,
  `fall`/`sink`/`portal`은 400ms 이하, `win`/`lose`는 1.5초 이하.
  꼬리가 길면 초당 열 번 나는 충돌음이 뭉개진다.
- 전체 합계 **50KB 이하**를 목표로 (`CLAUDE.md` 2절의 "빌드 100KB 미만").
  96kbps mono 기준 150ms짜리가 약 2.6KB니까 20개는 들어간다.
- 피크는 **-3dBFS**로. 코드가 세기에 따라 게인·피치·로우패스를 같이
  조절하니 **원본은 가장 세게 친 소리 하나**만 있으면 된다.
- 24bit/스테레오로 줘도 된다 — 변환은 이쪽에서 한다. 다만 좌우가 동일한
  파일이면 스테레오는 그냥 용량 두 배다.

### 실제로 처리한 예 (`hit.wav`)

받은 파일: 24bit 스테레오 48kHz, 0.40초, 123KB.
- 좌우 채널 차이 **0.0000** → 완전한 모노, 스테레오는 순수 낭비였다
- **진짜 타격이 0.030초 지점에 있었다** — 앞의 30ms는 -36dB짜리 룸톤이라
  무음 감지기로는 안 잡히지만 귀에는 "소리가 늦게 난다"로 들린다
- 0.16초 이후는 -45dB 아래 꼬리
→ 0.028~0.172초를 잘라내고 페이드, 모노 44.1k, -3dBFS, mp3 96k =
**2.6KB**. 원본은 `_to_delete/audio-sources/`에 옮겨뒀다.

## 4. 무료 음원 사이트 (상업 이용 가능)

라이선스는 직접 확인한 것만 적었다. 받기 전에 개별 파일의 라이선스 표기를
한 번 더 볼 것 — 사이트 정책과 개별 업로드가 다른 경우가 있다.

### 추천 순서

1. **[Pixabay Sound Effects](https://pixabay.com/sound-effects/)** — 가장 무난하다.
   [Content License](https://pixabay.com/service/license-summary/) 요약:
   **상업 이용 가능, 출처 표기 불필요.** 금지되는 건 "파일 자체를 그대로
   재판매/재배포하는 것"인데, 게임에 넣는 건 여기 해당 안 된다.
   검색어: `stone hit`, `marble click`, `wood knock`, `pebble`, `click wood`
   - 바둑돌 클랙에 제일 가까운 건 **마블(구슬) 부딪히는 소리**나
     **작은 돌멩이끼리 치는 소리**다. "stone"으로만 검색하면 바위가
     굴러가는 큰 소리가 대부분이라 잘 안 맞는다.

2. **[Freesound](https://freesound.org/)** — 품질이 가장 좋지만
   **파일마다 라이선스가 다르다.** 반드시 **CC0** 필터를 걸 것
   (CC-BY는 크레딧 표기 의무가 생기고, 포털 제출 게임에선 표기할 자리가
   마땅치 않다). 검색어: `go stone`, `baduk`, `marble click`, `stone
   click`, `glass marble`
   - 계정 가입이 필요하다.

3. **itch.io 무료 SFX 팩** — 팩 단위라 변형을 한 번에 얻는 게 장점이다.
   각 팩 페이지의 라이선스 문구를 꼭 확인할 것.
   - [Marbles SFX](https://fullydesigned.itch.io/marbles-sfx) — 구슬 충돌.
     `impact` 용도로 가장 근접해 보인다.
   - [Free Stones and Debris SFX Pack](https://rawambience.itch.io/free-stones-and-debris-sfx-pack) — `obstacle`/`fall` 쪽.
   - [Free Click Sound Effects Pack](https://hoveaudio.itch.io/free-click-sound-effects-pack) — `button`/`flick`.

4. **[Mixkit](https://mixkit.co/free-sound-effects/click/)** — 받기는 쉬운데
   Sound Effects Free License 전문을 이번에 확인하지 못했다
   (페이지가 링크 뒤에 있음). **쓰기 전에 라이선스 본문을 직접 읽을 것.**

### 고를 때 팁

- `impact`는 **바둑돌/유리구슬/작은 자갈** 소리를 찾는다. 실제 바둑돌
  클랙은 에너지가 **1.5~6kHz**에 몰린 아주 짧고 밝은 소리다. 낮고 둔한
  "톡" 소리는 돌끼리가 아니라 **나무판에 놓는** 소리라 여기엔 안 맞는다.
- `obstacle`은 같은 계열이지만 **더 둔하고 짧게** — 고정된 말뚝은
  울리지 않고 흡수한다.
- `sink`는 "떨어져 들어가는" 깊이감이 필요하다. 낮고 살짝 리버브가 있는
  것을 고르면 좋다.
