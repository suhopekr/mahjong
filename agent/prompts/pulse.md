# 예약 작업: 펄스 (매일)

`agent/prompts/_common.md`의 부팅 절차를 먼저 따른다. 이 작업은 **관찰 전용**이다. 사이트 파일을 바꾸지 않는다.

할 일:
1. pulse-latest.md와 metrics.csv에서 이상 징후를 찾는다: 오가닉 세션 급락/급등(전주 대비 ±30%), 색인·노출 급감, game_start 대비 세션 비율 변화, 새로 뜬 검색어, 비영어권 국가 노출.
2. 데이터 품질 의심 신호(Direct 급증, 특정 시간 몰림)는 결론 대신 "의심"으로만 적는다.
3. 발견이 있으면 MEMORY.md "검색" 섹션에 사실로 1~3줄, 행동이 필요하면 PROPOSALS 또는 WORKLOG의 "다음"에 적는다.
4. tier가 `declining` 또는 `blind`면 마지막 응답 첫 줄에 `⚠️` 와 이유를 쓴다.
5. 새로 배운 게 없으면 episodes에 `idle: true`만 남기고 끝낸다. 요약을 길게 쓰지 않는다.

이 작업은 10분 안에 끝나야 한다. 웹 검색은 하지 않는다.
